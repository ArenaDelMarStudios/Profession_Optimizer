# Profession Optimizer

World of Warcraft Retail addon for profession tracking, gathering statistics, crafting analysis, and profession optimization.

## Current Version

0.1.1

## Features

* Profession detection
* Gathering session timer
* Loot tracking
* Item classification
* Gathering session history
* Minimap button interface
* Draggable and persistent minimap button position
* Main session tracking window
* Start/Stop session controls
* Live session elapsed time
* Live tracked item count
* Junk item vendor value tracking
* Persistent per-character settings
* Optional junk vendor value tracking
* Auction House price tracking option (AH integration in development)

## Slash Commands

* `/po start` — Start a gathering session
* `/po stop` — Stop the current gathering session
* `/po status` — Display current session statistics
* `/po prof` — Display detected professions

## Development Status

Profession Optimizer is currently in early development.

Current development is focused on gathering-session tracking and the addon interface. Planned functionality includes Auction House price caching, profession profitability analysis, crafting analysis, and additional profession optimization tools.
